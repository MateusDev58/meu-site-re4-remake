# Resident Evil 4 Remake  Projeto Front-End

Projeto desenvolvido para praticar React, responsividade e componentização, inspirado no site oficial de Resident Evil 4 Remake.

Resident Evil 4 sempre foi um dos meus jogos favoritos, então decidi usar o remake como inspiração para criar um projeto de portfólio e colocar em prática meus conhecimentos de Front-End.

## O que foi desenvolvido

- Interface inspirada no site oficial
- Layout responsivo para diferentes tamanhos de tela
- Componentização com React
- Animações com AOS
- Carrosséis utilizando Swiper
- Rolagem suave com Lenis

## Tecnologias

- HTML5
- CSS3
- JavaScript
- React
- Vite
- Swiper
- AOS
- Lenis
